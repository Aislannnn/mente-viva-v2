# Design

A paleta abaixo vem da interface existente e está centralizada em `lib/core/design_tokens.dart`. Ela pode ser ajustada em um único ponto quando a referência de design do Figma estiver disponível.

| Uso | Cor |
| --- | --- |
| Azul principal | `#1848B0` |
| Verde do cuidador | `#0F6E56` |
| Fundo claro | `#F5EFE6` |
| Superfície escura | `#1A1A2E` |
| Roxo de apoio | `#7B5EA7` |
| Âmbar de apoio | `#BA7517` |

O tema usa Material e permite modo escuro, alteração de fonte e escala de texto. Esta documentação descreve a interface atual; ela não presume que a versão local já reflita um arquivo específico do Figma.
